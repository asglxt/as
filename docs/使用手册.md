# 学校管理系统 — 使用手册

更新日期：2026-09-14

## 1. 登录与角色

用浏览器打开系统地址（本地示例：`http://localhost:5173`），输入账号密码登录。

系统有四类角色：

| 角色 | 能做什么 |
| --- | --- |
| 行政 | 管理全校区的学员、班级、课程、排课、成绩、订单、财务、报表、角色权限 |
| 教师 | 查看自己任教的班级与学员，排课、记上课、录成绩、写点评、布置与批改作业 |
| 家长 | 查看自己孩子的成绩、点评、作业、订单与账户 |
| 学生 | 查看自己的成绩、点评、作业 |

左侧菜单会按权限显示；没有权限的模块不会出现。

## 2. 开校第一步：初始化顺序

按这个顺序把基础数据建好，后面的功能才能串起来：

1. **组织架构**：建校区（如「八一新校区」「河西校区」），必要时在下面建部门。
2. **角色权限**：建角色（如「教务」「前台」「财务」），勾选模块权限与适用校区，再把员工分配到角色。
3. **员工**：建教师和员工账号。
4. **课程**：先建「课程类别」「科目设置」，再建课程（含授课模式、收费模式、开课校区）。
5. **教室**：按校区建教室（如 8 教室、307）。
6. **班级**：建班，指定所属课程、校区、班主任、助教、满班人数、开班日期、上课时间。
7. **学员**：录入或批量导入学员（Excel/CSV）。
8. **分班**：把学员分到班级（选择报读课程）。
9. **报读与课时**：给学员报读课程，录入购买课时与学费（或走订单收款自动生成）。
10. **排课**：给班级排课（时间、教师、教室）。
11. 之后每天：**记上课** → **点名** → 系统自动扣课时。

## 3. 行政 / 教务日常操作

### 3.1 排课

1. 左侧「排课」→ 选择周次 → 点「排课」。
2. 选择班级、校区、日期、开始/结束时间、教师、教室。
3. 保存。若教师、教室或班级在该时段已有课，系统会提示冲突并拒绝保存。
4. 支持四种视图切换：时间课表 / 教师课表 / 教室课表 / 班级课表。

### 3.2 记上课与点名（每天必做）

1. 左侧「记上课」→ 选日期（默认今天）。
2. 列表显示当天所有课（班级、课程、教师、校区、教室、状态）。
3. 点「记上课」→ 列出该班学员 → 逐个选择：到课 / 缺课 / 请假 / 补课。
4. 保存后：这节课标记为「已记录」，学员课时自动扣减，并生成课时流水。
   - 到课扣 1 课时；缺课默认扣 1 课时；请假不扣；补课扣 1 课时。
5. 漏记的课可以事后补记；「课时汇总」页签可查每个学员的购买/已用/剩余课时。

### 3.3 成绩

1. **项目设置**：维护测评类型（听写、单元测评、期中、期末、入学测…）。
2. **考试设置**：维护具体考试（第一单元、期中考试…）。
3. **成绩录入**：选班级 + 项目 + 考试 + 日期 + 来源 → 表格里逐个填分数和备注 → 保存（同一学员同一项目同一考试同一天重复保存会自动覆盖）。
4. **成绩查询**：按学员/班级/项目/考试/日期筛选，支持导出 CSV。
5. **批量导入**：在「导入」页选择「成绩」，上传 CSV，模板列：
   `student_name,class_name,project_name,exam_name,exam_date,score,source,remark`
   导入后会显示逐行校验结果（哪一行哪一列有问题）。

### 3.4 课堂点评

1. 左侧「课堂点评」→ 列表按上课记录展示（学员数、已点评数）。
2. 点某节课的「点评」→ 逐个学员填写评分、评语、小红花。
3. 可先在「点评模板」里建常用评语，然后「应用到全部学员」，再个别修改。
4. 家长端看完后会自动记录「已读」，用于统计阅读率。

### 3.5 作业

1. 左侧「作业」→「布置作业」：选班级、填标题与内容、设截止时间。
2. 可以「保存草稿」稍后再发；点「发布」后自动给该班每个在读学员生成一条作业记录。
3. 列表里能看到：学员数、已提交、已批改、未读。
4. 点「批改」→ 查看提交内容 → 打分 + 写评语。

### 3.6 报读与课时

1. 左侧「报读」→ 选学员、课程、校区，填购买课时与学费 → 新增报读。
2. 课时调整：点「调整课时」，正数增加、负数减少，**必须填备注**（会写进流水）。
3. 点「课时流水」查看每一笔课时变动（购买/消耗/调整/退费）与变动后余额。

### 3.7 订单与收款（前台 / 财务）

1. 左侧「订单」→ 选学员、订单类型（报名/续费/充值/转课/退费/教材）、校区。
2. 添加明细：课程课时（选课程、填课时数与单价）或教材杂费（填名称、数量、单价）。
3. 保存后系统自动算应收。
4. 点「收款」→ 选收款方式（现金/微信/支付宝/银行卡/余额抵扣）+ 金额 → 确认。
   - 支持分次收款，订单会显示「未收款 / 部分收款 / 已结清」与欠费金额。
5. 报名/续费订单**付清后**会自动生成课时账户（购买课时与学费）。
6. 「明细」可查看订单明细与收款记录，并可打印收据。

### 3.8 学员账户

- 「学员账户」：查余额、积分与流水；可手工调整余额（必填备注）。

### 3.9 退费

1. 左侧「退费」→ 选学员 → 选报读记录。
2. 系统按「剩余课时 × 课时单价」给出建议退费金额。
3. 可修改实际退费金额（如扣手续费），**必须填写退费原因**，选退款方式。
4. 确认后：剩余课时清零、课时与金额流水记录、必要时退回学员余额。

### 3.10 报表

左侧「报表」，五个页签：经营总览 / 招生与学员 / 教务 / 财务 / 员工。

- 顶部可按校区多选、选择时间范围与粒度。
- 指标卡可点击下钻看明细（新增报名、欠费、退费、课时消耗），支持导出 CSV。
- 用途：校长看经营总览与财务；教务看排课与出勤；市场看新增学员与校区对比。

### 3.11 通知公告（行政 / 教务 / 校区主管）

1. 左侧「内部管理」→「通知公告」，顶部铃铛也会直接进入通知中心。
2. 「模板库」可维护停课、活动、教务和财务等常用模板，新建通知时可一键套用。
3. 新建通知可选发送范围：全校员工、指定校区或指定班级；班级通知会发送给班主任、家长和相关学生账号。
4. 可保存草稿、提交审核或直接发布。审核中的通知可由有权限的账号审核通过或填写原因驳回。
5. 列表显示送达人数、已读人数和阅读率；点「详情」可查看每个接收人的阅读状态。
6. 已发布通知可填写原因后撤回，收回后仍保留历史记录和阅读数据。

### 3.12 教材与杂费（行政 / 教务 / 财务）

1. 左侧「办理管理」→「教材与杂费」，「教材库存」可新增教材，填写所属校区、售价、成本价、期初库存和预警值。
2. 点「调整库存」可做采购入库、退回入库、手工领用或盘点调整，所有变动都会写入库存流水。
3. 在订单里选择教材商品后，未发放项目会进入「待领用与流水」；确认领用后自动扣减对应校区库存，库存不足时不会发放。
4. 「杂费设置」可维护教材费、资料费等杂费项，指定适用课程和关联教材，并开启「报名或续费时自动带入订单」。
5. 启用自动带入的杂费会随报名/续费订单产生；如果关联了教材库存，也会生成待领用记录。

### 3.13 成绩分析与预警

1. 学员详情中新增「成绩分析」页签，可查看成绩成长曲线、最近成绩、平均分和最高分。
2. 班级排名按同一项目、考试和考试日期在该班内计算。
3. 同年级机构排名按相同考试在全校同年级学生中计算。
4. 最近成绩比上一次提高或下降 3 分时显示趋势；下降 5 分触发下滑提醒，下降 10 分及以上触发红色预警。
5. 最近成绩低于班级平均分 5 分以上时，会显示低于平均分提醒。
6. 「成绩」页面新增「成绩分析」页签，可按学员姓名、学员编号、家长手机号模糊搜索，并可叠加班级筛选；选择学员后查看完整分析。
7. 工作台会显示成绩预警数量，点击学生可直接进入对应学员详情。

### 3.14 班级考试评级

1. 左侧「教学管理」→「成绩」→「班级评级」。
2. 系统按每次考试的实际录入成绩计算班级平均分。
3. 评级规则：
   - 平均分 `95 分及以上`：`S班`
   - 平均分 `90 分及以上、低于 95 分`：`A+班`
   - 平均分 `低于 90 分`：`启航班`
4. 列表同时展示最高分、最低分、参考人数和任课教师，可按班级筛选。
5. 教师只能看到自己任教班级的评级结果。

### 3.15 成绩来源设置

1. 成绩来源分为三个一级分类：机构内、学校内、其他第三方。
2. 左侧「教学管理」→「成绩」→「考试设置」→「成绩来源」可维护二级考试来源。
3. 新建成绩时可选择任意已启用的二级来源，系统会记录完整来源路径。
4. 来源可新增、改名、停用和启用；已有成绩使用的来源不能删除，避免历史数据失去来源。
5. 一级来源下如果还有二级来源，需要先处理二级来源再删除。
6. 教师只能选择来源，不能修改来源配置。

7. 「考试设置」中还包括「考试项目」和「考试名称」两个子页签，分类设置集中在一个入口。

## 4. 教师操作要点

### 4.1 手机教师端

- 教师账号可从主登录页的“教师端登录”进入，也可直接打开 `/teacher/login`；登录后自动进入手机教师端。
- 手机端底部有「首页、考勤、作业、成绩、课时」五个入口。
- **考勤**：选择当天课程开始点名，到课、缺课、补课扣 1 课时，请假不扣。
- **作业**：可布置作业、保存草稿、查看提交情况，并逐人填写成绩和点评。
- **成绩**：选择班级和考试后，直接录入整班成绩并保存。
- **课时**：按班级查看剩余课时，可快速划扣或返还 1 课时。
- 教师只能在手机端看到自己任教的班级和学生。

### 4.2 桌面端操作

- 只能看到自己任教的班级和学员。
- 每天在「记上课」里给当天的课点名。
- 在「成绩」里录自己班级的成绩。
- 在「课堂点评」里给学生写评语与小红花。
- 在「作业」里布置作业、批改。
- 看不到订单、财务、报表等模块（除非管理员另外授权）。

## 5. 家长 / 学生端

### 5.1 家长手机端

- 家长账号可从主登录页的“家长端登录”进入，也可直接打开 `/parent/login`；登录后自动进入手机家长端。
- 多个孩子可以在页面顶部切换，成绩、点评、作业和账户会同步切换。
- **首页**：查看最近成绩、未读点评、待完成作业、账户余额和最新动态。
- **成绩**：查看考试项目、分数、考试日期、班级和老师备注。
- **点评**：查看老师评分、小红花和评语，并可标记已读。
- **作业**：查看作业要求与截止时间；未提交的作业可由家长协助填写并提交，批改后查看评分和评语。
- **账户**：查看余额、积分、订单记录和账户流水。
- 家长只能查看自己已绑定孩子的数据。

### 5.2 桌面端家长 / 学生页面

登录后左侧会显示：

- **孩子成绩 / 我的成绩**：按考试与项目展示分数、来源、日期、班级与备注。
- **孩子点评 / 我的点评**：查看老师评语、评分、小红花；点「标记已读」后老师能看到阅读率。
- **孩子作业 / 我的作业**：查看作业内容与截止时间，填写内容后「提交作业」，老师批改后可看到评分与评语。
- **孩子订单 / 我的订单**：查看订单记录、账户余额与流水。
- **通知公告**：查看学校、校区或班级发送的通知，打开后自动标记已读。

## 6. 常见问题

| 问题 | 处理办法 |
| --- | --- |
| 登录后看不到某个菜单 | 该账号的角色没有这个模块权限，联系管理员在「角色权限」里勾选 |
| 记上课保存后课时没变 | 检查学员是否已报读该课程并有课时账户；只有报读过才会扣课时 |
| 成绩重复录入 | 同一学员+项目+考试+日期 会覆盖，不会产生两条 |
| 导入失败 | 按错误提示检查具体哪一行哪一列；校区名、班级名、项目名、考试名必须与系统里一致 |
| 退费金额不对 | 系统建议值 = 剩余课时 × 单价；如与实际不符，可手工调整并填写原因 |
| 家长看不到数据 | 确认家长账号已绑定该学员（通过邀请码绑定） |
| 打印 | 订单明细页与家长端成绩页均有打印按钮，使用浏览器打印即可 |

## 7. 建议的日常节奏

- **每天**：记上课 + 点名；必要的课堂点评。
- **每周**：检查待处理欠费、课时不足学员；布置与批改作业。
- **每月**：导出成绩与财务数据、核对账户余额与课时流水、做一次数据库备份检查。

## 8. 试用数据

- 管理员可在项目目录执行 `pnpm run seed:trial`，为当前所有启用校区生成试用数据。
- 默认每个校区 10 个班、5 名中文教师、每班 20 名中文学生；班级名称按“校区拼音简称 + 教室 + 级别”生成。
- 教师试用账号为 `teacher1`～`teacher20`，家长试用账号为 `parent1`～`parent4`，密码统一为 `123456`。
- 该命令可重复执行，用于补齐或更新试用数据，不会重复创建同一批教师、教室、班级和学员。
